## Task 6: Fix `Positions.jsx` — DirectionBadge Null Fallback

**Problem:** `DirectionBadge` defaults to `▲ LONG` for ANY row where `signal_name` and `signal_type` are null or HOLD. Old V4 rows and HOLD signals all appear as LONG.

**Files:**
- Modify: `frontend/src/pages/Positions.jsx` (lines ~11-14)

- [ ] **Step 1: Fix DirectionBadge component**

Current code:
```jsx
function DirectionBadge({ row }) {
  const name = (row.signal_name || row.signal_type || '').toUpperCase();
  if (name === 'SHORT') return <Badge variant="danger">▼ SHORT</Badge>;
  return <Badge variant="success">▲ LONG</Badge>;
}
```

Replace with:
```jsx
function DirectionBadge({ row }) {
  const name = (row.signal_name || row.signal_type || 'UNKNOWN').toUpperCase();
  if (name === 'SHORT') return <Badge variant="danger">▼ SHORT</Badge>;
  if (name === 'LONG' || name === 'BUY') return <Badge variant="success">▲ LONG</Badge>;
  // HOLD, UNKNOWN, null — show neutral badge
  return <Badge variant="secondary">— {name}</Badge>;
}
```

Read `frontend/src/components/ui/Badge.jsx` (or wherever Badge is defined). Confirm `secondary` variant exists. If not, use the closest neutral variant (e.g., `"default"` or `"outline"`).
